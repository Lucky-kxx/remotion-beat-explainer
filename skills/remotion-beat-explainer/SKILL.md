# Remotion 卡点科普视频

优先复用当前工作区已有的 Remotion 工程、动画、音频工具和通过版。新项目默认 1920×1080、60 fps、16:9、中文字幕；用户要求无配音时只用字幕、配乐和合成音效。仅有文件读取时也可以打开对应目录下的 `SKILL.md`，让相对资源路径以该目录为基准。

## 创作

1. **确认素材与交付范围。** 优先用用户提供的纯配乐。需要分析参考视频时，用 FFmpeg 抽关键帧、切镜与音轨；有实际讲话且需要理解台词时才转录。看不到素材时说明实际拿到的内容。现有素材、代码动画和本地工具足够时，优先复用，避免重复安装与云端生成。
2. **写一条能复述的主线。** 每个镜头回答一个问题。可用 01/02/03 组织章节，开章大字在下一镜缩成提示。用已有留白加简短读图提示或逐步高亮流程；字幕较密时收敛。逐句把文案和画面、可读时长对应，保留用户观点并核实关键事实。
3. **测音再定镜。** 运行 [scripts/analyze_beats.py](scripts/analyze_beats.py)，拿到 BPM、拍点和低频起音候选。听辨实际要用的重音与小节首拍。做全片整数帧的分镜/动作/音效清单，过场从已有锚点切入。脚步声对落地帧，按画面挑合成音色，优先保留能听出同步的动作音。
4. **每段可单独试看。** 在 Remotion 用帧驱动动画、共用 timing 配置；配乐轨和动作音效分开。用户要先看一段就按其确认节奏；拿代表帧和短样片查文字、动作、节奏，完整合成沿整首音乐原有次序。用户指定的片段优先修，既有画面和节奏继续复用。

## 修改与验收

- **仅改画面/字幕**：记录通过版，锁分镜长度和起点。仅渲染受影响镜头或透明叠层，替换到原帧号；从通过版流复制完整音轨。用 [scripts/media_timing.py](scripts/media_timing.py) 检查所有视频时间戳与 AAC 音频包。片头、片尾或其他需逐帧保留的区域检查边界帧，有条件时流复制。
- **修配乐**：先排除参考音频本身隐藏的跳段。把纯源和通过版接点前的同一个乐句对齐，优先一次接入原音轨并连续向后走。整体音量明显不同才做一次固定增益匹配。保留已通过的部分，避免按章节重开音乐、用循环补时长，或拿局部 EQ 掩盖真实跳段。音乐长度不够时先按本次授权决定自然收尾、压缩未锁定画面或放弃少数非必要卡点。
- **封面**：独立出同分辨率 PNG。静态封面与播放器首帧是两件事。需要浏览时也能看到封面、且平台从第 0 帧取图时，按用户指定长度加封面头帧，再接原首镜。上一条发布版用 0.1 秒（60 fps 下 6 帧），这是可复用选项。
- **导出**：保留通过版文件，另存修订版。核对首帧、首个动作、每个改动边界、片尾、分辨率、帧数、音轨和轨道相对时差。帧号与音频验收的执行方法见 [references/timing.md](references/timing.md)。

调用示例（Codex）：`$remotion-beat-explainer 用我提供的脚本和配乐制作 60 fps 横屏科普，先做 10 秒样片。`
